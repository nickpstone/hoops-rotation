# 🏀 Hoops Rotation

Phone web app for fair basketball sub rotations by position.

- Set which positions (1–5) each player may play
- Tick who's playing today
- Get a full-game rotation that subs every few minutes, keeps minutes as even as possible and keeps players in their allowed positions
- Sub timer with beep/vibrate, live swaps, injury/late-arrival re-planning

Open it on your phone and use **Add to Home Screen** to install. Works offline.
